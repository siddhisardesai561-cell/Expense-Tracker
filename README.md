# Expense-Tracker

## About the Project
C Expense Tracker is a menu-driven application developed using the C programming language. It helps users manage their daily expenses by adding, viewing, and editing expense records.

## Features
- Add new expenses
- View all saved expenses
- Edit existing expenses using Expense ID
- Store records in a binary file
- Simple menu-driven interface

## Technologies Used
- C Programming Language
- Structures and Functions
- File Handling
- Binary Files

## Concepts Used
- `struct`
- User-defined functions
- `switch` statement and loops
- File operations using `fopen()`, `fread()`, and `fwrite()`
- File operations using `remove()` and `rename()`

## Future Improvements
- Delete an expense
- Search expenses by category or ID
- Calculate total expenses
- Generate monthly expense reports
